Instalação

São duas peças. A maioria das pessoas só precisa da primeira.

O plugin do Figma

Publicado para a organização acaso. Abra qualquer arquivo de Design ou Slides e encontre o tofig nos plugins da sua organização. Não há mais nada para configurar — sem conta e sem chave de API.

A CLI do renderizador (opcional)

Só é necessária para exports que o sandbox do plugin não consegue rodar. Veja Renderizador externo para saber quando é o caso.

npm install -g @aca-so/tofig

Requer Node e um Google Chrome ou Chromium local. O puppeteer-core usa o navegador que você já tem em vez de baixar um.

Começo rápido

  1. Abra um arquivo de Design ou de Slides no Figma.
  2. Rode o tofig pelo menu de plugins.
  3. Cole seu HTML, ou solte um arquivo .html na janela.
  4. Clique em Converter.

O tofig lê o figma.editorType e escolhe a saída por você: frames num arquivo de Design, slides num arquivo de Slides. Não existe seletor de modo.

O que o tofig aceita

HTML self-contained. Na prática, tudo o que a página precisa está no arquivo:

  • <style> inline e atributos style=""
  • Imagens como URIs data: / base64
  • <svg> inline
  • Web fonts que já existam no seu Figma

URLs externas nunca são baixadas. O plugin declara networkAccess: none no manifest, então o Figma bloqueia requisições de saída por completo. Uma folha de estilo ou imagem atrás de https:// simplesmente não vai estar lá. Isso é intencional: é o que torna seguro apontar o plugin para um markup que você não escreveu.

O layout é posicionado de forma absoluta. O tofig otimiza para fidelidade visual — o que você vê é onde cai — em vez de reconstruir auto-layout. Inferência de auto-layout está no roadmap.

Fontes e substituição

O Figma só consegue compor texto com fontes que já tem. Quando seu HTML pede uma que não está disponível, o tofig percorre uma cadeia de fallback:

  1. A família pedida, no peso e estilo pedidos.
  2. O peso disponível mais próximo na mesma família.
  3. Inter.

Toda substituição é reportada na UI do plugin depois da conversão, então você sabe exatamente quais camadas mudaram e por quê. Se o texto parecer um pouco menor depois de importar, é o passo de ajuste: uma fonte de fallback costuma ocupar mais altura e, como cada camada é posicionada de forma absoluta, o tofig reduz o texto para mantê-lo dentro da caixa medida em vez de deixá-lo invadir o elemento de baixo.

Renderizador externo

Alguns arquivos com extensão .html são, na verdade, aplicações. Eles inicializam um runtime React, baixam React ou Babel de uma CDN, chamam eval ou leem localStorage. O sandbox de plugins do Figma bloqueia tudo isso, então eles não conseguem renderizar dentro do plugin.

Para esses casos, renderize na sua máquina num Chrome sem restrições e importe o resultado. Mesmo extrator, mesma saída — só que sem sandbox.

# gera export.tofig.json ao lado do arquivo
tofig-render export.html

# ou sem instalar nada
npx --package=@aca-so/tofig tofig-render export.html

Depois solte o .tofig.json resultante no plugin, ou use Choose…. Ele importa direto, sem passo de renderização interna.

O arquivo .tofig.json

Um payload JSON simples — a árvore de camadas extraída, já resolvida em geometria, estilos e bytes de imagem embutidos. É determinístico: a mesma entrada gera o mesmo arquivo, o que o torna revisável e diffável.

{
  "tofig": 1,
  "target": "slides",
  "title": "deck",
  "multiFrame": true,
  "roots": [ /* uma entrada por frame ou slide */ ]
}

Como o payload carrega os próprios bytes, o plugin nunca precisa de acesso à rede para importá-lo — a propriedade de segurança se mantém de ponta a ponta.

Solução de problemas

Nada renderiza, ou o resultado sai em branco

O export provavelmente é uma aplicação, não markup estático. Use o renderizador externo.

As imagens sumiram

Quase certamente são URLs externas. Embuta-as como URIs data: e exporte de novo.

Texto sobrepondo texto

Uma substituição de fonte ocupou mais altura que a original. O tofig reencaixa o texto na caixa medida, mas um design muito apertado ainda pode ficar espremido. Instale a fonte real no Figma e rode de novo.

A tipografia ficou um pouco menor que a original

Esperado e intencional — veja Fontes e substituição. Um glifo levemente menor é o preço de não haver sobreposição.

Uma camada aparece para fora do frame

Não deveria acontecer a partir da 0.3.1, que recorta cada raiz capturada ao próprio frame. Se acontecer, abra uma issue com o HTML.

Compilar do código

O repositório é público e licenciado sob MIT.

git clone https://github.com/aca-so/tofig
cd tofig
npm install
npm run build        # gera code.js + ui.html

Depois, no app desktop do Figma: Plugins → Development → Import plugin from manifest… e escolha o manifest.json deste repositório. Há dois exemplos em examples/ — um para Design e um para Slides.
