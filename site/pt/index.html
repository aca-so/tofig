Receba camadas.

O tofig reconstrói HTML self-contained como nós nativos do Figma — frames de verdade, texto vivo, vetores editáveis. Não é uma captura de tela. Abra num arquivo de Design e saem frames; abra no Slides e saem slides.

Três passos, sem conta

A UI do plugin é um navegador de verdade. Ela renderiza seu HTML num iframe oculto, lê os estilos computados e a geometria, e reconstrói cada elemento como um nó nativo.

  1. Abra o tofig

    Num arquivo de Design ou de Slides. O tofig lê o figma.editorType e escolhe a saída certa sozinho.

  2. Cole ou solte

    Cole o markup direto, ou solte um arquivo .html. CSS inline, imagens data: e SVG inline vêm junto.

  3. Converta

    Você recebe frames, texto que dá para reescrever, vetores editáveis, imagens, gradientes, bordas e cantos arredondados.

Um plugin, dois destinos

Onde você roda define o que sai. Não há modo para escolher.

Arquivo de Design

Frames na tela

Cada raiz capturada vira seu próprio frame, recortado nos seus limites — assim um filho que transborda fica contido em vez de aparecer atrás da prancheta. Um deck de várias seções chega como um frame por seção.

Arquivo de Slides

Slides de verdade

O tofig reconhece decks — inclusive os feitos em JavaScript — e importa cada slide como um slide do Figma, dimensionado para caber em vez de ser cortado.

O que sobrevive à viagem

E, igualmente importante, o que não sobrevive. Estes limites são reais — conhecê-los agora sai mais barato que descobri-los às 2h da manhã.

Texto continua texto
Reescreva, reestilize, requebre linha. A tipografia é mapeada para o peso e o estilo mais próximos entre as suas fontes do Figma.
SVG inline vira vetor
Paths editáveis na tela, não um raster achatado.
Preenchimentos, gradientes, bordas, raios
Reconstruídos como paints e propriedades nativas do Figma.
Fontes ausentes são substituídas
Se a fonte não estiver no seu Figma, o texto cai na correspondência mais próxima, depois Inter — e o tofig informa exatamente o que mudou.
O layout é posicionado de forma absoluta
Escolha feita por fidelidade visual. Auto-layout está no roadmap; hoje você tem posicionamento preciso, não restrições responsivas.
URLs externas nunca são baixadas
O plugin declara networkAccess: none. Deixe seu HTML self-contained: estilos inline, imagens data:, SVG inline.

Quando um export não renderiza

Alguns arquivos chamados de "HTML" são, na verdade, aplicações. Eles inicializam um runtime React, baixam React ou Babel de uma CDN, ou usam localStorage. O sandbox de plugins do Figma bloqueia tudo isso, então eles não renderizam dentro do plugin.

Isso é um limite do sandbox, não um bug.

Sem rede e com origem data: é exatamente o que torna seguro rodar o plugin sobre markup não confiável. A alternativa preserva essa propriedade.

Renderize o arquivo num Chrome real e sem restrições na sua máquina, e depois importe o resultado. Mesmo extrator, mesma saída — só um navegador sem sandbox. Solte o .tofig.json gerado no plugin e ele importa direto.

Requer um Google Chrome ou Chromium local. Continua 100% local — nada é enviado para lugar nenhum.

# uma vez só, sem instalar
npx --package=@aca-so/tofig tofig-render export.html

# ou instale
npm install -g @aca-so/tofig
tofig-render export.html --target slides

Gera export.tofig.json ao lado do arquivo de entrada. O --package= é necessário porque o binário tem nome diferente do pacote.

Instalar o tofig

O plugin está publicado para a organização acaso no Figma. O renderizador é uma CLI separada e opcional.

Plugin do Figma

Abra qualquer arquivo de Design ou Slides e encontre o tofig nos plugins da sua organização. Compilar do código-fonte também funciona — clone o repo, rode npm run build e importe o manifest.
