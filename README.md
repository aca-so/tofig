# tofig

> Export HTML and other formats — such as Claude-generated designs — to Figma.

[![CI](https://github.com/tiagomoraes/tofig/actions/workflows/ci.yml/badge.svg)](https://github.com/tiagomoraes/tofig/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

> [!NOTE]
> **tofig is in early development.** The product specification and toolchain are
> still being defined, so APIs and structure may change. This repository
> currently holds the project scaffolding and contribution guidelines.

## What is tofig?

tofig aims to take rendered output — HTML and other formats, including designs
generated with Claude — and bring it into [Figma](https://figma.com) as native,
editable design layers.

## Status

🚧 Pre-alpha. See open issues and the `develop` branch for in-progress work.
